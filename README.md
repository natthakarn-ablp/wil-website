# SMART(2015) WiL Website

เว็บไซต์โครงการ WiL — โรงเรียนในโรงงาน สำหรับสื่อสารรูปแบบการเรียนรู้ที่เชื่อมการศึกษาเข้ากับประสบการณ์ทำงานจริงในภาคอุตสาหกรรม

## เริ่มต้นใช้งาน

```bash
npm install
npm run dev
```

เปิด `http://localhost:3000`

## ตรวจสอบ Production Build

```bash
npm run build
npm start
```

## เทคโนโลยี

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS 4
- Radix UI

> ข่าว วันที่รับสมัคร และเงื่อนไขบางส่วนในเวอร์ชันแรกเป็นเนื้อหาตัวอย่าง กรุณายืนยันข้อมูลทางการก่อนเผยแพร่สู่สาธารณะ
